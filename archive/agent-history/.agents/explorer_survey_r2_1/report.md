### 3.2 Feature Properties Schema
Each feature in `features` contains:
```json
{
  "type": "Feature",
  "geometry": {
    "type": "Polygon" | "MultiPolygon",
    "coordinates": [ ... ]

  "properties": {

    "layer_id": 1,
    "zone_type": "prohibited",

```

#### Field Details:
1. `id` (string): Numeric string ID assigned by `cambay.mod.gov.vn` PBF vector tiles (e.g. `"14129"`, `"14706"`).
2. `layer_id` (integer):
   - `1`: **Vùng cấm bay (Prohibited)** — Absolute prohibition. Total: **2,378 features**.
   - `2`: **Vùng hạn chế bay (Restricted)** — Conditional / restricted operations. Total: **367 features**.
3. `zone_type` (string):
   - `"prohibited"` (maps 1:1 to `layer_id: 1`)
   - `"restricted"` (maps 1:1 to `layer_id: 2`)
4. `source` (string): Always `"https://cambay.mod.gov.vn"`.
5. **Altitude fields**: **None**. Neither `floor`, `ceiling`, `min_altitude`, nor `max_altitude` exists. All zones apply from ground level to upper operational ceiling.
6. **Name fields**: **None** in the GeoJSON. The vector tiles from Cambay MOD do not encode public civilian names (for national security).
   *(Note: `backend/app/geofence.py:53` checks `properties.get("name", properties.get("rawName", "Vùng kiểm soát"))`, defaulting to `"Vùng kiểm soát"` when evaluated).*

## 5. Integration Architecture Analysis (Backend & Frontend)

### 5.1 Backend Serving & Evaluation Pipeline
1. **File Storage**: `backend/data/zones.geojson` (8.2 MB).
2. **API Endpoint**: `GET /api/v1/geofence/zones` in `backend/app/main.py:246-249`:
   ```python
   @app.get("/api/v1/geofence/zones")
   def geofence_zones(_=Depends(require_admin)):
       if not settings.zones_path.exists():
           return {"type": "FeatureCollection", "features": []}
       return json.loads(settings.zones_path.read_text(encoding="utf-8"))
   ```
   - **Access Control**: Currently protected with `require_admin`. Anonymous or unauthenticated frontend requests receive `401 Unauthorized`.
3. **Geofence Engine Ingestion**: `backend/app/geofence.py:30-40`:
   - `GeofenceEngine.load()` loads all features using Shapely `shape(feature['geometry'])`.
   - Ingestion benchmark: ~476 ms on desktop Python, ~1.8 s on Raspberry Pi 5 CPU.
   - Point-in-polygon evaluation: Checks point containment against each geometry; if safe, calculates minimum distance to boundary points via `shapely.ops.nearest_points`.
4. **Database Sync Metadata**: `backend/data/drone.sqlite3` table `map_sync`:
   - Contains: `(id=1, source_url='https://cambay.mod.gov.vn', fetched_at='2026-09-02T19:34:28.177523+00:00', checksum='a06204a4a2f6b92ebc0e2bfa32b8fe9740987cc209ab9b30f8f461ba857fdc0e', feature_count=2745, status='ready')`.
   - `geofence_sync_is_fresh()` checks if `fetched_at` is within 24 hours. Because `fetched_at` was 2026-09-02, preflight evaluates `geofence_sync_is_fresh = False`.

### 5.3 Root Cause of User Invisibility Issue
Why did the user report that the map didn't show the zones?
1. **Map Pack Dependency (`status.map_ready`)**:
   In `frontend/src/App.tsx:135`, the map container only initializes if `status.map_ready` is `true`. `status.map_ready` depends on `settings.map_path.exists()` (`backend/data/maps/hcm.pmtiles`). On development machines without `hcm.pmtiles`, the map never initializes, rendering the empty fallback screen.
2. **Authentication Gate**:
   `GET /api/v1/geofence/zones` requires admin authentication. If an unauthenticated user or camera viewer loads the page, the API returns `401`/`403`, and the map displays no zones.
3. **GeoJSON Payload Size**:
   Transferring an uncompressed 8.2 MB JSON over LAN takes significant time and MapLibre parsing overhead.
